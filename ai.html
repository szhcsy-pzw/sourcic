💡 怎么描述效果最好？

像跟采购同事说话一样自然就行。说得越具体，AI 解析越准。关键字段：型号 / 品牌厂家 / 器件大类 / 封装规格 / 精度或等级 / 环保要求 / 替代意向。不必全填，有什么说什么。

📋 场景一：知道完整型号——直接报型号最准

手头有完整料号，直接贴进来，AI 精确匹配。

🔧 场景二：只记得型号片段+关键参数——组合描述

记得品牌系列名 + 封装 + 用途，AI 帮你模糊匹配。

🎯 场景三：不确定型号——按功能用途描述

不知道具体型号？说出功能、应用场景，AI 帮你定位品类。

🇨🇳 场景四：找国产替代——指定原型号求 Pin-to-Pin 替代

供应链安全或降本需求，说"国产替代"触发推荐国产品牌。

📦 场景五：批量采购——带上数量和交付要求

报上预估用量和交期要求，方便卖家精准报价。

📝 描述技巧： ① 有型号就报型号，最准 → ② 没型号就报「品牌 + 品类 + 关键参数」 → ③ 加上封装（如 0603/QFP64/SOT-23）能大幅缩小范围 → ④ 有特殊要求（环保/车规/工业级/国产替代）一定带上 → ⑤ 批量采购加上数量和交期，方便卖家报价
